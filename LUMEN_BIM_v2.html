Gerador de script Blender

Gera um script Python que lê o JSON exportado, cria uma coleção de luminárias, monta geometrias paramétricas esquemáticas ou associa objetos-base pelo código e grava propriedades personalizadas em cada objeto.

Preparação IFC

Os objetos recebem propriedades com nomes consistentes para futura exportação IFC:

IDENTIDADECode / Name
DESEMPENHOLuminousFlux / Power
FOTOMETRIABeamAngle / CCT / CRI
ELÉTRICAVoltage / IPRating
MANUTENÇÃOLifetime
GEOMETRIADimensions / Type
Importante: o script Blender prepara a cena e os dados. Para gerar IFC nativo, instale e configure o complemento Bonsai (IfcOpenShell) no Blender e faça a exportação IFC pela ferramenta BIM. Atributos personalizados, sozinhos, não garantem um IFC semanticamente completo.
